# 露卡统一功能调用与音乐

更新：2026-09-15。先喊“露卡”，听到回应后说指令；监控页文字框也会实际执行明确指令。

| 功能 | 说法示例 |
|---|---|
| 动态目的地 | 有哪些航点；去书桌；去厨房 |
| 停止 | 停止；停止导航；停止巡航 |
| 巡航 | 开始巡航录像；查询巡航路线；把巡航路线设为厨房、卧室、浴室 |
| 原地录像 | 开始录像；停止录像；查看录像状态 |
| 录像找物 | 帮我找剪刀；剪刀在哪里；带我去找剪刀；带我去 |
| 当前相机识别 | 识别当前画面的剪刀 |
| 定位 | 查询定位状态；自动重定位（须停车，完成后核对地图） |
| 服务 | 查询服务状态；启动小车功能 |
| 声纹 | 查询声纹状态 |
| 聊天 | 正常聊天保留短期记忆；清空聊天记忆 |
| 说话音量 | 把说话音量调大；把说话音量调小 |
| 音乐 | 播放晴天；暂停音乐；继续音乐；停止音乐；音乐音量设为30 |

航点读取客户页面已确认的目的地。路线只保存，不自动出发。工具执行前验证目标来自原话，不能让模型编造坐标。停止或手柄接管会使尚未提交的模型导航指令失效。带路前仍要求有效观察位置、当前定位和导航状态。

注册、密码、联网配置、地图框选改名、声纹录入、手动定位等需要在对应页面完成；大模型提供入口说明。重启功能在监控页操作。电梯与首次自主建图仍是待办。按用户要求，超声波采集、导航障碍层和停车保护保持关闭。

音乐状态（2026-09-16更新）：已接入 ALAPI 网易云搜索和歌曲直链，正式使用 https://v3.alapi.cn/api/music/search 与 /api/music/url。token 仅保存在 NX 的 /home/sunrise/luka_ws/common/state/alapi_music.json（权限 0600），通过请求头发送给 ALAPI，不在网页或日志中展示。已实际搜索并播放“成都 赵雷”，暂停、继续和停止通过测试；本次平台返回约43秒音频，小于歌曲总时长，会提示试听片段。部分歌曲需会员或无播放权限，无法保证完整播放。旧 apiopen 接口不再使用。


音乐入口位于监控页与客户页。唤醒露卡会暂停正在播放的音乐，之后说“继续音乐”；播报会临时降低音乐音量。下载有限时、大小限制，拒绝私网歌曲地址，mpv 只读取已下载的本地文件。

验证：11项新工具测试、7项找物带路测试、7项巡航路线测试、2项播报测试；本地模型只选择工具测试；真实只读接口和定位语音播报；播放器静音播放/暂停/继续/音量/停止。未发起实车移动测试。
