# 语音合成与播放重叠

保留现有 VITS 中文模型、音色 14、速度 1.2、CPU 四线程。按逗号及句末标点分段，最长 16 字；长分句超过限制时按长度切分。不是逐帧流式模型，分段处自然度仍需实际听感确认。

独立合成线程按序准备音频，独立播放线程按序播放，准备队列最多两个片段。播放当前片段时继续合成下一片段或下一句话。短语缓存与唤醒缓存继续使用。合成、待播、播放期间及尾音保护期间屏蔽麦克风。

- 第一段可播放：旧版 2.950 秒，新版 2.673 秒，改善约 0.28 秒。不是秒回。
- 两句之间，旧版第一句播放结束后继续等约 3.44 秒合成；新版第一句最后一段结束到第二句第一段播放启动约 0.002 秒。此为进程日志间隔，实际音频仍包含标点停顿、设备启动及首段 0.2 秒保护静音。
- 新版两句话拆为四段，四段均播放完成，最后恢复唤醒监听。没有发送导航或底盘动作。
