# NX 低速点动验收

用户已确认可以实车点动，并说明下层雷达旋转90度且存在车架回波。范围为一次约2cm/s、0.5秒的前进短点动；未开放导航。

核对现有90度外参、下雷达 inverted、角度过滤和融合源码后，保留原融合与自过滤配置。没有扩大自过滤范围或删除近处回波。点动检查改用 /scan_obstacle_fused 在 laser→base_link 坐标转换后的点与原车0.56×0.38m footprint 的距离：四周扩展3cm覆盖短点动及1秒独立停止计时器行程，再要求至少5cm余量。此检查仅适用于本次速度/时限，不可直接用于更快或更长时间运动。

同时要求上下雷达、融合和IMU数据新鲜，融合帧能在下雷达历史中找到150ms以内的对应帧。修正了以最新下雷达帧比较低频融合帧造成的误拦截。使用独立本机停止进程，在1秒期限到达时再次向四个电机发停止命令；主流程0.5秒即停止。串口写超时150ms；临时暂停只读里程计避免串口竞争，结束后恢复。

单元验证覆盖坐标转换、前后侧障碍、过期数据、扫描同步、无有效回波和某一电机停止发送失败时仍尝试其他电机。test_pulse_guard.py 通过。

第一轮实际点动0.042秒，因上述帧同步检查误判提前停止，四个电机转速均回到0。证据 nx_forward_pulse_early_stop.json。

修正后完成0.501秒点动，四电机位置增量分别+11.6、-11.2、+11.3、-11.6度。按原车几何折算 dx=0.01013m、dy=-0.000155m、dyaw=-0.0000667rad；这些是编码器推算，实际轮向/地面运动仍需现场观察核对。四电机最终反馈转速均0，主停止无异常，独立计时器也执行停止。证据 nx_forward_pulse_result.json。

nx_forward_pulse.py 默认为仅预检；只有 --execute 才可能发送速度命令。未把该入口接到网页或设置自启动。当前定位、传感器、监控保持运行，原底盘控制节点和导航控制器未启动。

## 左转短点动

用户确认前进无偏转，并已授权继续低速验证。增加受限 left 模式（四个电机均-4rpm，原方向映射下为正yaw），复用0.5秒时限和独立停车进程。已执行一次；末尾保存结果时发现局部变量 args 被 /proc 枚举列表覆盖，导致 AttributeError。停车和恢复只读里程计先于保存操作执行；独立再次读取四个电机确认全部速度为0。真实完整脉冲结果与当时IMU采样未落盘，不以模拟结果代替。

真实停车复查位置分别0.3、-23.0、0.5、-23.2度；相对前进测试结束时11.7、-11.4、11.4、-11.8度的变化符合左转方向，估计约1.7度，仍需现场核对。证据 nx_left_stop_verification.json。

已将进程枚举变量改为 proc_args，避免覆盖命令参数。新增 test_pulse_flow.py 对完整左转流程做ROS、串口、进程信号和看门狗的模拟测试，验证结果文件保存、停止反馈与恢复读取流程；模拟完全不访问硬件，没有为补日志再次驱动车轮。

## 延长直行与车架回波

用户允许多走并确认环境安全。首先尝试1秒预检，因已知车架回波在5cm保护边界附近波动而拦截，未发运动指令。核对转向前后同一近回波仍位于车身 x约0.36m、y约0.19m，与用户说明的车架一致后，增加 nx_chassis_filter.py：只屏蔽下雷达转换到base_link后 x=[0.350,0.380]、y=[0.175,0.205] 的小矩形，保留其他回波。该区域会成为不可观测区，若支架或雷达安装变化需重新标定。附近约0.43m的低位目标仍可见。

为避免仅消除回波而缩小碰撞体，短点动保护轮廓前沿扩大到0.38m、侧面±0.21m，另保留3cm移动覆盖和5cm净距。原 Nav2 footprint 尚未同步这个突出部件，导航仍未开放；接通导航前必须完成整车轮廓核对。原融合角度变换和其他自过滤保持不变，额外过滤节点输入/输出为 scan_low_raw→scan_low_chassis_filtered，再进入原融合。

约束时长仅允许0.5或1秒；独立停止期限调整为1.2秒，4rpm时最大理论位移约2.55cm，在3cm覆盖内。坐标/掩膜边界、近障保留及保护测试通过。

实际1秒直行完成1.0046秒，电机增量+23.6、-23.8、+23.6、-23.3度，折算前进2.090cm、横移0.011cm、偏航-0.0038度；四电机速度归零，主停止和独立停止均完成。证据 nx_forward_1s_result.json。

传感器重启导致AMCL待初始化，已用重启前估计位置加这次编码器增量作为宽协方差初值，再用真实雷达完成5次静态更新恢复显示；位置仍是待实车复核的估计，不能把均值恢复当成准确定位验收。
