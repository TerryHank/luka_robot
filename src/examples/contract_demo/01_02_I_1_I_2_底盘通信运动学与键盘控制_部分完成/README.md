# 01 + 02 底盘通信运动学与键盘控制演示

本目录合并合同I-1、I-2的实际运行演示，合同索引仍保留两条原文。
入口是真正的ROS2 launch，不再只打印离线Python计算结果。

    ./demo.sh

launch启动/复用现有安全底盘适配器及双雷达传感器，启动teleop_twist_keyboard，
并持续订阅编码器反解的/wheel/odom。在当前终端输入按键，使用SSH时必须带-t：

    ssh -t sunrise@192.168.3.150

i前进，,后退，j/l转向，Shift+J/L横移，k或空格停车，Ctrl+C退出整个launch。
默认0.1m/s、0.2rad/s。按住按键使终端产生连续输入；无新命令时底盘超时停车。
键盘仅接/nx/web_teleop_cmd_vel，保留原有编码器、双雷达新鲜度、近障和暂停门控。
其他手动发布者、未知串口所有者或只读里程计占用底盘时，入口拒绝重复启动。

终端持续显示：
- x/y（米）、yaw（度）；
- 由测量反馈反解的vx/vy/wz；
- 本次观测累计measured_path（米），来自实测位姿差值；
- 底盘安全门状态。
没有有效编码器数据时显示WAITING，不把键盘速度指令当作里程。

只观察已有里程计、不启动设备和键盘：

    ./demo.sh start_hardware:=false keyboard:=false

退出Ctrl+C或在另一终端执行./stop.sh。launch只关闭自己创建的进程，
已经运行的生产底盘/传感器服务仍保留。实际为麦克纳姆，不是合同字面差速；
没有STM32固件/CAN交付物，本目录仍标部分完成。
本轮未发送实车键盘移动命令，运动效果待现场验证。
