# NanoOWL 巡航录像检索

入口：http://192.168.3.251:8091/view 。生产识别后端已切换为 NanoOWL/OWL-ViT TensorRT；模型按需加载，空闲 60 秒自动卸载。

1. 点击「开始录像」，手动缓慢移动相机巡视。
2. 点击「停止录像」。下方选择这段录像。
3. 输入物体名称，点击「搜索录像」。逐张显示候选截图、检测框、拍摄经过时间和 AVI 播放时间。
4. 需要边移动边看时，在「开始连续识别」中输入目标；服务每 0.4 秒读取一帧最新画面，连续两帧位置一致后才显示为确认目标，点击「停止连续识别」结束。录像搜索同样要求相邻关键帧重复出现后才列为命中。

支持取消搜索、历史结果及 AVI 录像下载。常见中文名称、颜色和部分位置描述会转换为英文提示词。候选框需人工核实，未检出不等于物体不存在；颜色和空间关系仍需现场复核。没有控制小车自动驾驶，也没有地图坐标或自动返回目标点功能。

## 数据与运行

- 录像：640×480，MJPEG AVI，目标 10 fps，单段最多 30 分钟。
- 关键帧：每 2 秒一次，448×336 JPEG，保存原始采集时间。
- 拍摄经过时间与 AVI 帧号换算的播放时间分别保存，以处理录制掉帧。
- 搜索串行使用同一个模型，与单张识别互斥；录制与搜索可以并行。
- 默认置信度阈值为 0.06；预测器保留较宽候选池，再由后处理和跨帧确认抑制误报；低照度画面会自动提亮后再识别；连续识别和录像搜索仍通过跨帧确认抑制误报；连续识别与拍照识别、录像搜索共用模型锁；忙时会跳过当前帧，不会叠加推理任务。
- 数据保存在 NX `/home/sunrise/luka_ws/perception/locateanything_trial_20260907/patrols`，不会自动删除历史录像。
- 空间不足 2 GiB 不开始录像，录制中低于 1 GiB 自动停止。相机断开也会停止并记录原因。
- 服务：`locateanything-preview.service`，已设置开机启动；原 LocateAnything-3B 运行链路已停用，8093 候选服务已关闭。
- 源码：`live_app.py`、`patrol.py`、`live.html`、`model_runtime_nanoowl.py`。复用原相机驱动和录像接口，TensorRT 图像编码器位于 NX `/home/nvidia/owl_image_encoder_patch32.engine`。
