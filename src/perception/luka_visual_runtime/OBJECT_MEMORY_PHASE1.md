# 物体观察记忆：第一阶段部署记录

2026-09-10，NX 192.168.3.251。

入口：http://192.168.3.251:8091/memory ，8503 顶部也有“物体观察记忆”链接。

## 已实现

- 停稳后输入物体名称，使用现有 LocateAnything 识别并保存 RGB-D 观察。
- 从 `/wheel/odom` 检查停稳状态；导航目标活动时拒绝新观察。模块不发布运动指令。
- 在拍摄时刻查询 `map → base_link` TF；查询失败时保留相机结果，不伪造地图位姿。
- 把模型 448 像素输入上的候选框缩放回 640×480 原图，再读取深度。
- 用框中心区域的有效深度中位数估算可见表面位置；深度不足或混合表面时不输出三维点。
- SQLite 持久保存观察索引；每条记录保留原图、深度 PNG、厂商内参、采集配对延迟、拍摄位姿、外参、识别框和位置结果。
- 网页可按本次观察使用的名称查询历史，或显示最近 50 条。当前是观察记录，不是已经去重合并的物体实例地图。

## 安装位姿

用户给出的尺寸：底盘中心到车头前缘 28 cm；镜头位于车头后 10 cm；左右居中；离地 20 cm；朝车头正前方，无俯仰。

据此镜头在底盘地面投影坐标中的平移为 `(0.18, 0, 0.20)` 米。光学坐标右/下/前转换到底盘前/左/上的四元数为 `(-0.5, 0.5, -0.5, 0.5)`，按 xyzw 排列。

外参来源标记为 `user_measurement`，`verified=false`，地图结果标记为 `estimated_manual_extrinsic`。当前二维 TF 的 base_link 高度为 0，按地面投影建模；机械尺寸、相机姿态和该坐标定义仍需现场核验。相机移动后应更新外参，旧记录保留原外参。

## 验证与边界

测试覆盖坐标轴变换、平移、缺失外参和无效深度、候选框缩放、数据库重新打开后的历史读取、未检出记录和文件路径限制。真实停车状态与拍摄时刻 TF 查询已验证。没有为测试下发移动目标。
