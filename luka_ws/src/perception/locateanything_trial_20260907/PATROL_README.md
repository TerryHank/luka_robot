# LocateAnything 巡航录像检索

入口：http://192.168.3.251:8091/view 。模型为 Q4_K 量化版，常驻 Orin NX GPU。

1. 点击「开始录像」，手动缓慢移动相机巡视。
2. 点击「停止录像」。下方选择这段录像。
3. 输入物体名称，点击「搜索录像」。逐张显示候选截图、检测框、拍摄经过时间和 AVI 播放时间。

支持取消搜索、历史结果及 AVI 录像下载。常见中文名称映射为英文提示词，其他自由描述建议输入英文。候选框需人工核实，未检出不等于物体不存在。没有控制小车自动驾驶，也没有地图坐标或自动返回目标点功能。

## 数据与运行

- 录像：640×480，MJPEG AVI，目标 10 fps，单段最多 30 分钟。
- 关键帧：每 2 秒一次，448×336 JPEG，保存原始采集时间。
- 拍摄经过时间与 AVI 帧号换算的播放时间分别保存，以处理录制掉帧。
- 搜索串行使用同一个模型，与单张识别互斥；录制与搜索可以并行。
- 数据保存在 NX `/home/sunrise/luka_ws/perception/locateanything_trial_20260907/patrols`，不会自动删除历史录像。
- 空间不足 2 GiB 不开始录像，录制中低于 1 GiB 自动停止。相机断开也会停止并记录原因。
- 服务：`locateanything-preview.service`。本阶段仍为临时服务，未设置开机启动；原 YOLO 服务目前停止。
- 源码：`live_app.py`、`patrol.py`、`live.html`。复用原相机驱动和 `build/locate-live` 模型进程。

## 验证

2026-09-07 在 NX 现场录制约 7.1 秒、71 帧 AVI、4 张关键帧。视频经 OpenCV 逐帧解码验证，尺寸及帧数正确。完成搜索、取消、历史读取、非法录像编号拒绝检查。瓶子搜索在 0、2、4、6 秒返回候选框；椅子搜索无候选。原始结果在工作区 `output/locateanything_trial_20260907/patrol_acceptance.json`。已检查 Python 和浏览器脚本语法。

这是短片段端到端验证，尚未完成长时间移动巡航的召回率评估。每 2 秒抽帧可能遗漏短暂出现的目标。若每张推理约 1.5 秒，一分钟录像的搜索量约为 30 张，实际耗时取决于画面与模型输出。
