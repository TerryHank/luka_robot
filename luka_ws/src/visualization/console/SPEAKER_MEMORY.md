# 声纹与个人短期记忆

已录入且本句声纹匹配可靠时，按声纹ID隔离聊天上下文。改称呼不会与其他人混用；删除声纹后对应内存记录会在两秒检查周期内清空。

每人最多最近6轮、1800字符上下文，闲置10分钟失效，语言代理重启后清空。聊天内容不新增磁盘保存；现有服务日志仍可能记录识别文本与回复。

每次只采用这一段录音对应的识别结果，不使用“最近说话人”全局状态。个人记忆要求候选匹配分数至少0.75，另保留声纹识别本身的多人差距判断。录音过短、低置信度、识别等待超时（最多额外等待1.5秒）均按本次访客对话处理，不延续别人的历史；未录入的访客之间也不共享历史。网页文字输入使用独立网页会话记忆。

清空当前人的记忆：唤醒露卡后说“请清空我的聊天记忆”。应说得清楚完整，确保声纹可识别；声纹未确认时只清空临时上下文，不会清空其他人的记录。

测试方法：
1. 已录入的甲说“露卡，我平时最喜欢喝的是乌龙茶，你记一下”。
2. 再次唤醒，说“露卡，你还记得我平时最喜欢喝什么吗”。
3. 乙录入自己的声纹后询问同样问题，不应得到甲的偏好。
4. 甲再次询问，应仍能接续甲的对话。

声纹是个性化候选，不是可靠身份认证；不要将它当作私密信息访问或运动权限控制。导航、找物、停车的既有路径保留，不因为声纹失败而阻止停车。
