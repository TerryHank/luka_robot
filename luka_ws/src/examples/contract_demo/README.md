# 合同条款与编号功能演示

依据用户提供的合同附件需求，按原顺序保留01至27条逻辑编号。01/02共享一个实际功能演示目录，每条原文仍对应一行。
合同总费用10000元、两期各5000元；没有逐功能价目，本文不编造金额分配。

此目录位于 ~/luka_ws/src/examples/contract_demo/；不在工作区根目录创建源码域。
生产配置不由演示入口修改。设备/算法入口以ROS launch启动实际组件并持续显示实时结果。
原已运行的服务不会被stop.sh停止；Ctrl+C/stop.sh仅停止当前launch创建的组件。
串口/相机有启动占用锁，完整已运行栈复用，部分栈/重复所有者拒绝启动。
SLAM与AMCL/static-map互斥。新版入口不再安装辅助systemd服务。

## 使用

    cd ~/luka_ws/src/examples/contract_demo
    ./menu.sh
    ./check_all.sh       # 只核对全部源码/入口
    ./stop_all.sh        # 停止记录的前台launch及历史入口遗留组件

也可进入任一编号文件夹，执行demo.sh。16、18、19、21为缺失项，27为服务承诺，
这些目录只提供check.sh和说明，不做假的功能演示。
23为已有接口资料盘点，26为交付资产盘点；它们不是完整合同交付验收。

终端启动成功只代表进程已运行。实时图像、扫描、里程计和定位仍需观察时间戳、
新鲜度与有效数据。源码存在、部署/离线检查通过、现场验收通过分别记录。
启动时不会自动发航点、巡航、Home、重定位或停靠请求；01_02由用户键盘输入经保护手动入口发速度。
01_02及导航相关项会启动/复用现有保护底盘节点；保持已有运动许可、安全门和超时。
Foxglove可连接 ws://192.168.3.150:8765；现有页面为 http://192.168.3.150:8503/。

## 统一实时launch演示方式（2026-10-08）

所有已有可运行设备/算法功能均通过各目录demo.launch.py启动，
demo.sh直接执行ros2 launch，终端持续显示真实消息或WAITING/STALE。
01/02合为一个底盘演示目录；03打印IMU轴数据（with_ekf:=true启用已有融合器）。
04/05打印扫描与RGB-D；09/10/11打印地图与定位；12–15、17、24打印路径、
安全链与任务状态；20打印语音/DOA；22提供识别叠加图；07/08/25显示实时接口/节点/诊断。
环境06、资料23、交付26是检查项，未实现16/18/19/21及服务27不伪造硬件演示。

### 统一命令

- 交互终端进入对应目录运行./demo.sh，或ros2 launch /绝对路径/demo.launch.py。
- ./check.sh只读检查；实时入口用./demo.sh --show-args查看参数。
- Ctrl+C/./stop.sh结束当前launch；主菜单也会进入相同launch。
- 按项演示先结束上一项。已有完整设备栈复用，部分栈/重复串口拒绝启动。
- 不同时运行SLAM和静态地图AMCL，以免重复发布地图/TF。
- start_hardware:=false仅供隔离测试/录制回放，不能当实车验收。
- 开始时不会自动发导航/巡航/返航目标。操作走现有页面及门控。
- 模型/地图/日志均在~/luka_data/；源码入口保持~/luka_ws/src/examples/。

启动成功、静态检查和模拟消息测试不等于实车运动或合同全部功能验收。
